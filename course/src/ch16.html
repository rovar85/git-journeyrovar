Variables: remembering facts

By the end of this lesson you can:
  • store a fact in a variable and use it again
  • tell text, numbers and true/false apart
  • print results and build a sentence from several facts

The idea

When you investigate a failing server you keep facts in your head: which server, which service, what state, how long it has been down. A program does the same with variables. A variable is a labelled box. You write the label on the left and the value on the right, joined by =. In Python = means "put this value into the box", not "is equal to".

Values come in a few basic kinds:

KindExampleUsed for
Text (a "string")"EV01"names, messages. Always inside quotes
Whole number42counts, minutes
Decimal number0.7measurements, averages
True or FalseTrueyes/no answers (a "boolean")

print(...) shows something on the screen. An f-string (text that starts with f") lets you drop variables into a sentence by putting their names in curly brackets. Lines that start with # are comments: notes for humans that Python ignores.

Line by line

  • server = "EV01" creates a box labelled server holding the text EV01. The next three lines do the same for the service, its status and the minutes down.
  • print("Checking", server) prints the word Checking and then the value of server, separated by a space. Notice that "Checking" is in quotes (literal text) but server is not (a variable to look up).
  • message = f"{service} on {server} is {status}" builds one sentence from three variables and stores it in a new box.
  • hours_down = minutes_down / 60 does arithmetic: / divides. + adds, - subtracts, * multiplies.
  • round(hours_down, 2) rounds to 2 decimal places. 42 ÷ 60 is 0.7.
  • is_urgent = minutes_down > 30 asks a question: is 42 greater than 30? The answer, True, is stored. A variable can hold the answer to a yes/no question.
Why this matters for agents

An agent's state (Chapter 7) is nothing more than variables: the goal, the evidence so far, the current hypothesis. Everything in the later lessons is built from boxes like these.

Lesson C1 in plain words

  • A variable is a labelled box: label = value.
  • Basic kinds: text in quotes, whole numbers, decimals, True/False.
  • print shows output. f-strings put variables inside sentences. # starts a comment.
  • A comparison such as > produces True or False.
