## 1. The loop, for this track

1. **Gather (fast pass).** Go through lessons 1 to 2 quickly: read the goals and the recap, run the commands, skim the rest. Use the **notes box** at the top of each lesson to dump what you learn and what confuses you.
2. **Refine.** Turn the notes into a map and cards (section 2 and section 3). Draw the map from memory first, then compare.
3. **Drill.** Work the flashcards (section 3), then the **Your turn** tasks and quizzes in each lesson.
4. **Round 2.** Run it again only on what is left (section 6): long scenarios, new tools, edge cases, odd details.

Open the whole toolkit any time from the **Study** button at the top: [Method](#study/method), [Drill](#study/drill), [Maps](#study/maps), [Notebook](#study/notebook).

## 2. The map: One habit: look it up the fast way

The reference is for recall under pressure. Practise searching it before you need it.

1. **Find**: Use the search box with the verb you want (list, delete, copy). Lessons: [1](#reference-1).
2. **Understand**: Read what it does and when to use it, not just the flags. Lessons: [1](#reference-1).
3. **Try**: Run it on something safe and read the output. Lessons: [2](#reference-2).
4. **Drill**: Use the practice bank until the common commands are automatic. Lessons: [2](#reference-2).

**Do this now:** [open the sketch pad for this track](#study/maps/reference), draw the path from memory, then reveal the map and fix what you missed. Paper or an iPad canvas works just as well. The map is a scaffold for recall: every topic in this track should hang from one of these hops.

## 3. Flashcards for this track

Add your own gaps as notes, and export to Anki from [Notebook](#study/notebook) if you prefer your own app.

## 4. Tips nobody tells you

- Flashcards on commands beat re-reading them: use the Drill view and pick 'commands'.
- Group commands by job (find, change, inspect) not by tool.
- Know three flags well for each command rather than thirty badly.
- When stuck, run it with --help first.
- Keep your own cheat sheet of what you actually used this week.

## 5. Read only these pages

When documentation links to eight more resources, you usually need one to three pages. For this track, start here (links are given from memory of stable documentation addresses; if one has moved, search the site for the title):

- [man pages online](https://man7.org/linux/man-pages/)
- [kubectl quick reference](https://kubernetes.io/docs/reference/kubectl/quick-reference/)
- [Git reference](https://git-scm.com/docs)

## 6. Round 2: make these boring

- Do the practice bank without opening the reference.
- Explain five commands you have never typed.
- Rewrite one long pipeline in two ways.
- Teach someone the three commands you use most.
