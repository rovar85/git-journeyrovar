The AI and Python tracks are built from public talks and your own study notes. They draw on Andrej Karpathy's "Intro to Large Language Models", the Stanford CS229 lecture "Building Large Language Models", Insop Song's Stanford webinar "Agentic AI", Barry Zhang's "How We Build Effective Agents" (Anthropic), Sayash Kapoor's "Building and evaluating AI Agents", Mahesh Murag's MCP workshop (Anthropic), Kam Lasater's "Let's Build An Agent from Scratch", and the PhiloAgents course videos by Miguel Otero Pedrido and Paul Iusztin. The Linux, networking, Docker, Git, Ansible and Terraform lessons were written for this course. Commands marked Real output were run on a Linux machine while building the page. Output marked Example output shows what you will typically see but was not run here. Tools change quickly, so check each tool's own documentation for the version you install.
