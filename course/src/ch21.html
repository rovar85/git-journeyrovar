Coding track · Lesson C6

Classes: the state of an investigation

By the end of this lesson you can:
  • read a simple class: attributes, methods, self
  • explain how a class can hold an agent's goal, evidence and hypothesis

The idea

So far, facts live in separate variables and actions live in separate functions. But an investigation is one thing: it has a goal, a growing list of evidence and a current hypothesis, and you do things to it (add evidence, print a report). A class bundles those together, like a case folder with a cover sheet and a set of standard procedures.

  • A class is a template. Writing Investigation("Why is indexing down?") makes one real folder from the template (an object).
  • __init__ runs once when the object is created and sets it up.
  • Variables that belong to the object are attributes, written self.goal. Functions that belong to it are methods.
  • self means "this particular object". It is always the first input of a method.

This is where agent state (Chapter 7) lives in real code. Frameworks do the same thing with larger state objects (for example, the LangGraph state in Chapter 13 that holds messages and the philosopher's context).

Watch it run

Look at the Variables box after the object is created: the whole object is shown with its attributes, and it changes as evidence is added.

Line by line

  • class Investigation: starts the template. Everything indented below belongs to it.
  • __init__(self, goal) stores the goal and starts an empty evidence list and a placeholder hypothesis.
  • add_evidence appends a fact and, if a new hypothesis is supplied, replaces the old one. The =None makes the hypothesis optional.
  • report builds lines of text. enumerate(..., start=1) counts the evidence from 1, and "\n".join(lines) glues the lines together with line breaks.
  • case = Investigation(...) creates the object. case.add_evidence(...) calls a method on it. Each call changes the object's own state.
Connect it to Chapter 7

Compare this output with the agent simulator: "Evidence so far" and "Working hypothesis" were exactly this object. The model decides the next action, and your code keeps the state. That is why Chapter 8 said you should be able to inspect what the agent knows at every step.

Lesson C6 in plain words

  • A class is a template for bundling data (attributes) and actions (methods).
  • self means "this object". __init__ sets it up.
  • Agent state is a class holding the goal, evidence and hypothesis.
